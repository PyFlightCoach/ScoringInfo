# Element segmentation

In the current client use **Adjust segmentation** in the manoeuvre view of the results page. You rarely need it: segmentation is automatic and optimised for the kindest score.

- Drag a plane on the ribbon to move the boundary between two principal elements.
- **Score current boundaries** recalculates with the boundaries exactly as set.
- **Optimise from current boundaries** runs the optimiser starting from them. If segmentation failed, place boundaries roughly, then optimise.
- **Reset boundary changes** restores the original boundaries.

[Full instructions](https://pyflightcoach.github.io/FCScoreDocs/instructions/manoeuvre_analysis/element_segmentation/)
