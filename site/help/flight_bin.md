# Load a BIN file

An older address for loading an ArduPilot log. The normal route is **Flight > Create**.

- Select your ArduPilot BIN file. Boot time, duration, logging rate and origin are shown.
- Optionally select a Flight Coach JSON file to use its box and manoeuvre splits.
- Press **Next** to go to the box page. You are warned if the logging rate is below 18 Hz.
- A warning is shown if the file is already on the database; you can still analyse it.

[Full instructions](https://pyflightcoach.github.io/FCScoreDocs/instructions/scoring/load_flight_data/)
