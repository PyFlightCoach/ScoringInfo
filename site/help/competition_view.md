# View a competition

Shows one competition. The page menu switches between two views.

- **Results**: scores for each competitor, round by round, with totals.
- **Running Order**: the order in which competitors fly.
- Contest directors can edit the competition, add competitors and link flights from here.
- Open the competition you want from the **Competition** menu or from the browse page.

[Full instructions](https://pyflightcoach.github.io/FCScoreDocs/instructions/competitions/)
