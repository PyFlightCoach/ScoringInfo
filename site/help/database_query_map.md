# Flight map

Shows a map of the flights returned by the current leaderboard query.

- Marker size reflects the number of flights at a site.
- Marker colour and the label show the highest score achieved at that site.
- Hover over a marker to see the pilots who fly there; the top scorer is marked with *.
- Change the flights shown on the **Leaderboards** page (schedule, filters), then return here.

[Full instructions](https://pyflightcoach.github.io/FCScoreDocs/instructions/database/)
