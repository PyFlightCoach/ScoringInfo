# Define the box

Place the aerobatic box so it matches where you flew. The box menu on the left has the controls.

- Choose an **Input Mode**: **Flight Coach Sites** (nearest saved sites), **Pilot, Centre**, **Pilot, Heading**, or **F3A Zone / FC JSON File**.
- **Open map view** shows the box over a map to check the position. **Reset box** goes back to the starting box.
- Warnings appear if the box is over 500 m from the flight or its elevation differs from the landing; **Reset elevation** fixes the latter.
- Press **Score** to choose schedules and split the flight automatically (**Start segmentation and scoring**), or choose **Split manoeuvres manually**.
- For AcroWRX flights with an embedded sequence, **Split and score AcroWRX sequence** is also offered.
- Select up to 4 schedules if the recording holds several.

[Full instructions](https://pyflightcoach.github.io/FCScoreDocs/instructions/scoring/box_definition/)
